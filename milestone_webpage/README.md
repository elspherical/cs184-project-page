# CS 184 Final Project Website

Static website for GitHub Pages.

## Publish
1. Create or open your GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and the `assets/` folder to the repository root.
3. In the repository, go to **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Wait for the published URL to appear in the Pages section.

Edit the content in `index.html` and the styling in `style.css`.
